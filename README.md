# titanic-ai

Для запуска
 - Склонировать репозиторий
 - Установить Settings -> Interpreter conda
 - Запустить
```conda env create -f environment.yml```
```conda activate titanic-ai```
 - Либо через pip (не тестировал)
```pip install --upgrade pip```
```pip install -r requirements.txt```
 - Параметры меняются в constants.py
 - Результат сохранится в /submission
